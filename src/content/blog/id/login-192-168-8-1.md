`192.168.8.1` adalah alamat IP default semua modem Huawei — Orbit Star 2, B310, B312, B525, B818, sampai E5577. Inilah pintu masuk ke halaman admin modem. Kalau kamu tidak pernah mengganti password, kombinasi default di bawah biasanya berhasil.

## Kombinasi default

| Modem | Username | Password |
| --- | --- | --- |
| Orbit Star 2 (B312-929) | `admin` | `admin` |
| B310 / B311 / B312 | `admin` | `admin` |
| B525 / B535 / B818 | `admin` | `admin` |
| E5573 / E5577 | `admin` | `admin` |

Beberapa unit tertentu (terutama modem dari operator tertentu) bisa memakai `user` / `user`, atau `admin` / `password`. Kalau halaman login menampilkan CAPTCHA atau tombol **Learn more**, biasanya modem sudah di-set ulang ke mode pabrik.

## Kalau password tidak bisa

Kemungkinan password sudah diganti. Cara aman: **reset ke pengaturan pabrik**.

1. Cari lubang kecil bertanda **RESET** di badan modem.
2. Tekan dengan peniti selama 10–15 detik sampai lampu berkedip.
3. Tunggu modem nyala normal, lalu login lagi dengan `admin` / `admin`.

Reset akan menghapus semua pengaturan — termasuk password WiFi dan konfigurasi band. Catat dulu kalau perlu.

## Password di HP-mu masih lupa?

Kamu juga bisa pakai [Huawei Manager](https://hm.cakson.my.id/id/) — aplikasi ini login dengan kredensial admin yang sama, lalu menyimpan sesi agar tidak perlu mengetik password setiap kali. Setelah login, kamu bisa [ganti password WiFi](https://hm.cakson.my.id/id/blog/change-wifi-password) atau [cek sisa kuota](https://hm.cakson.my.id/id/blog/cek-kuota-orbit-star-2) langsung dari HP.

## Catatan keamanan

- **Ganti password default** segera setelah instal. Modem yang masih `admin`/`admin` gampang diakses orang lain di jaringan WiFi yang sama.
- Jangan bagikan kredensial admin ke siapa pun.
- Kalau internet terasa lambat setelah login, baca [penyebab dan solusinya](https://hm.cakson.my.id/id/blog/fix-slow-internet).
