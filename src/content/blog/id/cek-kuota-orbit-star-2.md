Kuota internet Orbit Star 2 bisa habis tanpa kamu sadari. Untungnya, modem B312-929 ini punya beberapa cara untuk cek sisa kuota — semuanya gratis dan tanpa aplikasi tambahan.

## Cek lewat halaman admin (192.168.8.1)

Cara paling standar:

1. Sambungkan HP ke WiFi Orbit Star 2.
2. Buka browser, ketik `192.168.8.1`.
3. Login pakai username dan password admin (default: `admin` / `admin`, atau lihat [password default](https://hm.cakson.my.id/id/blog/login-192-168-8-1)).
4. Buka menu **Home** atau **Dashboard**.

Di dashboard akan terlihat sisa kuota bulanan, pemakaian hari ini, dan pemakaian bulan ini. Beberapa firmware menampilkan masa aktif paket juga.

## Cek lewat aplikasi Huawei Manager

[Unduh Huawei Manager](https://hm.cakson.my.id/id/) lalu login dengan kredensial admin yang sama. Di dashboard, aplikasi menampilkan pemakaian data harian dan bulanan langsung dari modem.

Lebih dari itu, kamu bisa aktifkan **pengingat kuota**: notifikasi muncul saat pemakaian data harian atau bulanan melewati batas yang kamu tentukan. Tidak perlu buka halaman admin setiap hari.

## Cek lewat SMS

Beberapa operator menyediakan kode USSD untuk cek kuota, misalnya `*888#` untuk Telkomsel. Hasilnya dikirim via SMS — dan Huawei Manager bisa membaca serta mencarinya lewat menu SMS.

## Kenapa penting cek kuota rutin?

- Hindari **kehabisan kuota di tengah pemakaian** penting.
- Deteksi **pemakaian mencurigakan** (misalnya perangkat lain nyedot kuota — cek [kelola perangkat WiFi](https://hm.cakson.my.id/id/blog/getting-started)).
- Pastikan **band LTE** yang aktif tidak bikin koneksi boros. Kalau sinyal lemot, baca [cara mengatasi internet lemot](https://hm.cakson.my.id/id/blog/fix-slow-internet).

Cek kuota tidak pernah semudah ini. Pasang aplikasinya, atur batas pemakaian, dan lupakan.
