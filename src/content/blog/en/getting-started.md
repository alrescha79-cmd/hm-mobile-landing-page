Huawei Manager talks directly to your modem over WiFi — no root, no cloud account. If you can open the modem's admin page in a browser, this app can control it. Here's the whole setup.

## 1. Connect to the modem's WiFi

Join the modem's WiFi network just like you do for the admin page. The app auto-detects the modem IP (`192.168.8.1`), so there's nothing to configure.

## 2. Log in

Use the same username and password as the Web UI. The app supports the classic Huawei XML API, which every compatible modem exposes on the same address.

## 3. Monitor and control

Once connected you get the full dashboard:

- **Signal** — RSSI, RSRP, RSRQ, SINR, and the active band, live.
- **Traffic** — realtime speedometer plus daily and monthly usage.
- **WiFi devices** — list, rename, kick or block connected devices.
- **SMS** — read, compose, send and search messages, when your modem exposes SMS.
- **LTE Band Lock** — pin specific bands or carrier aggregation combos for a steadier connection.

## Tips for a stable connection

- Keep the phone on the same WiFi network as the modem.
- If login fails, confirm the password matches the admin page exactly.
- The app remembers the connection, so you only log in once.

That's it. Download the APK, join the WiFi, log in, and take control.
