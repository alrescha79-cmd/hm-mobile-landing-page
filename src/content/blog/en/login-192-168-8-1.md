`192.168.8.1` is the default gateway address for every Huawei modem: the Orbit Star 2, B310, B312, B525, B818, and the E5577 series. This address is the door to the modem's admin page. If you have never changed the password, one of the default combinations below should work.

## Default Credentials

| Modem | Username | Password |
| --- | --- | --- |
| Orbit Star 2 (B312-929) | `admin` | `admin` |
| B310 / B311 / B312 | `admin` | `admin` |
| B525 / B535 / B818 | `admin` | `admin` |
| E5573 / E5577 | `admin` | `admin` |

Some carrier-locked units use `user` / `user` or `admin` / `password`. If the login page shows a CAPTCHA or a **Learn more** button, the modem is typically in factory mode.

## When the Password Does Not Work

The password was probably changed. The safe fix is a **factory reset**.

1. Find the small pinhole labeled **RESET** on the modem.
2. Press it with a pin for 10 to 15 seconds until the lights flash.
3. Wait for the modem to boot, then log in again with `admin` / `admin`.

A reset wipes all settings, including the WiFi password and band configuration. Note down any settings you need to keep before resetting.

## Security Notes

- **Change the default password immediately after setup.** A modem still using `admin` / `admin` is easy for anyone on the same WiFi to take over.
- Never share your admin credentials.
- If the internet feels slow after logging in, read the [causes and fixes](https://hm.cakson.my.id/en/blog/fix-slow-internet).
