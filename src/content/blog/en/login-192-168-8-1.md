`192.168.8.1` is the default IP address of every Huawei modem — Orbit Star 2, B310, B312, B525, B818, all the way down to the E5577. It's the doorway to your modem's admin page. If you've never changed the password, one of the default combinations below usually works.

## Default combinations

| Modem | Username | Password |
| --- | --- | --- |
| Orbit Star 2 (B312-929) | `admin` | `admin` |
| B310 / B311 / B312 | `admin` | `admin` |
| B525 / B535 / B818 | `admin` | `admin` |
| E5573 / E5577 | `admin` | `admin` |

Some carrier-locked units use `user` / `user` or `admin` / `password`. If the login page shows a CAPTCHA or a **Learn more** button, the modem is usually in factory mode.

## When the password doesn't work

The password was probably changed. The safe fix: **factory reset**.

1. Find the small pinhole labelled **RESET** on the modem.
2. Press it with a pin for 10–15 seconds until the lights blink.
3. Wait for the modem to boot, then log in again with `admin` / `admin`.

Reset wipes all settings — including your WiFi password and band configuration. Note those down first if you need them.

## Still forget the password?

You can also use [Huawei Manager](https://hm.cakson.my.id/en/) — it logs in with the same admin credentials and keeps the session, so you don't retype the password every time. Once logged in, you can [change your WiFi password](https://hm.cakson.my.id/en/blog/change-wifi-password) or [check your data usage](https://hm.cakson.my.id/en/blog/cek-kuota-orbit-star-2) straight from your phone.

## Security notes

- **Change the default password** right after setup. A modem still on `admin`/`admin` is easy for anyone on the same WiFi to take over.
- Never share your admin credentials.
- If the internet feels slow after logging in, read [the causes and fixes](https://hm.cakson.my.id/en/blog/fix-slow-internet).
