Running out of data without warning is annoying — and on a Huawei modem like the Orbit Star 2 (B312-929) there are several ways to check your remaining quota, all free and without extra apps.

## Check via the admin page (192.168.8.1)

The standard way:

1. Connect your phone to the modem's WiFi.
2. Open a browser and go to `192.168.8.1`.
3. Log in with your admin credentials (default is usually `admin` / `admin` — see [default passwords](https://hm.cakson.my.id/en/blog/login-192-168-8-1)).
4. Open **Home** or **Dashboard**.

The dashboard shows remaining monthly data, today's usage, and this month's usage. Some firmware versions also show the active plan period.

## Check with the Huawei Manager app

[Download Huawei Manager](https://hm.cakson.my.id/en/) and log in with the same admin credentials. The dashboard shows daily and monthly data usage pulled straight from the modem.

Even better: enable **usage alerts**. A push notification fires when your daily or monthly data crosses a threshold you set — no need to open the admin page every day.

## Check via SMS

Many operators offer a USSD code to check data, for example `*888#` on Telkomsel. The result arrives by SMS — and Huawei Manager can read and search those messages in its SMS section.

## Why check data regularly?

- Avoid **running out of data mid-use**.
- Spot **unusual usage** (like another device draining your quota — see [managing WiFi devices](https://hm.cakson.my.id/en/blog/getting-started)).
- Make sure your **active LTE band** isn't causing a wasteful, flaky connection. If things are slow, read [why your modem is slow and how to fix it](https://hm.cakson.my.id/en/blog/fix-slow-internet).

Checking your data has never been this easy. Install the app, set a limit, and forget about it.
